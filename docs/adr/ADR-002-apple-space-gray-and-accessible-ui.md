# ADR-002: Палитра Apple Space Gray, доступный CustomSelect и единый стиль SVG-иконок

## Статус
Принято (Accepted)

## Контекст
В ходе аудита мобильной и десктопной версий были выявлены проблемы:
1. Нативный HTML `<select>` на мобильных устройствах открывал системное меню ОС с резким контрастом, ломавшим дизайн тёмной темы.
2. Иконки предметов в сетке категорий отображались в разнородном стиле (буквы "∑", "A", "Я", эмодзи "🧪", "💻", разный цвет для Python и пустой квадрат у ОРТ).
3. Цветовая гамма темной темы содержала резкий контраст между `#000000` в навигации и более мягким фоном контента.

## Решение
1. **Apple Space Gray Palette**:
   - Основной фон: `--color-bg: #1C1C1E` (RGB: 28, 28, 30).
   - Поверхности и шапка: `--color-surface: #242426`.
   - Карточки и выпадающие списки: `--color-bg-elevated: #2C2C2E`.
   - Границы: `--color-border: #3A3A3C`.
   - Устранены все жесткие хардкоды `#000000`.
2. **Доступный CustomSelect**:
   - Создан компонент `CustomSelect.tsx` с поддержкой ARIA (`role="combobox"`, `role="listbox"`, `role="option"`, `aria-expanded`).
   - Поддерживает навигацию с клавиатуры (стрелки, Enter, Escape) и закрытие по клику вне области.
3. **Единый набор иконок предметов**:
   - Разработан компонент `SubjectIcon.tsx` с 10 векторными линейными SVG (24px, `stroke="currentColor"`).
   - Все иконки окрашиваются через CSS-переменную `var(--color-primary)` / `accent-icon`. Добавлена иконка для категории «ОРТ».

## Последствия
- Полная визуальная согласованность между страницами и темами оформления.
- Соответствие стандартам доступности (WCAG 2.1 AA) по контрасту и клавиатурному управлению.
